# 合并冒烟清单：性能 / 组件复用 / 编辑器 / 命名统一（第 32–51 章）

> 用途：一次性跑完 **R154–R179** 所有前端改动的验证。
> 原分章用例在 `TEST-CASES.md` 第 30–51 章，本清单是**去重后的可执行版**。
>
> **预计耗时：35–45 分钟**（P0 约 25 分钟，P1 约 10 分钟，P2 可选）

---

## 怎么跑

1. 前端 **硬刷新**（Ctrl+Shift+R），确保拿到新 chunk
2. 打开 **F12 → Console**，全程留意红错
3. 按 P0 → P1 → P2 顺序点，**每条勾选 ☐ → ☑**
4. 失败用文末模板记录

**判定失败的标准**（满足任一即失败）：

| 现象 | 含义 |
|---|---|
| 控制台红色报错 | 运行时错误 |
| 点击无反应 / 数据不刷新 | 处理器没接上 |
| 翻页后数据没变 | `@current-change` 没接对 |
| 列表全空但接口 200 | 数据绑定断了 |
| 遮罩一直不消失 | `loading` 没复位 |
| **页面空白但菜单高亮正常** | 组件没解析到（`lazy-loading` 相关） |
