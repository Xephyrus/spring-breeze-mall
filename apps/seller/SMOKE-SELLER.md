## 失败时怎么定位

| 现象 | 最可能原因 | 检查 |
|---|---|---|
| 菜单点进去空白 | `li_store_menu.front_route` 与文件名不一致 | 跑 `backend/DB/store-menu-kebab-front-route.sql`；比对磁盘文件 |
| 侧边栏整个消失 | 动态路由名与 `hasRoute("otherRouter")` 不匹配 | 看 `libs/util.ts` 的 `STATIC_ROUTE_NAMES` |
| 页面打开但数据为空 | 接口 404（后端路由未变，前端 path 改了） | Network 面板看请求 URL |
| 组件不渲染、无报错 | 模板里引用了被删的 import | 控制台搜 `Failed to resolve component` |
| 跳转 404 | 代码里写死了旧 path（`/orderList`） | `grep -r "/orderList" apps/seller/src` |
| 登录后仍跳登录页 | cookie 名不是 `userInfoSeller` | `libs/axios.ts` 与 `router/index.ts` |
